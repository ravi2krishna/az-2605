    -> Datacenter 

        -> A data center is a physical facility or building that houses 
        groups of networked computer servers, data storage drives, and network equipment 
        used by companies to store, process, and share digital information and run applications.
                    
        -> https://datacenters.microsoft.com/wp-content/uploads/2025/11/OMB-Datacenter-11_11-Hero.jpg

        
        -> Main Parts Of Datacenter

            -> Servers: 
                
                -> High-power computers that process data and run software programs.

            -> Storage Systems: 
            
                -> Hard drives and arrays that hold large amounts of digital files and records.

            -> Network Gear: 
            
                -> Routers, switches, and firewalls that move data safely in and out of the facility.

            -> Cooling and Power: 
            
                -> Heavy-duty air conditioners, fans, backup generators, and power grids to 
                keep machines running non-stop.

                -> How To Calculate Subnet Size 

                    Total NW Bits are 32 
                    Result = Total NW Bits - Your Size 
                    No Of Devices / IP Addresses - 2 ^ Result 

                    16 = 65536

                    16 - Result = 32 - 16 i.e 16 - No Of Devices / IP Addresses - 2 ^ 16 = 65536 
                    20 - Result = 32 - 20 i.e 12 - No Of Devices / IP Addresses - 2 ^ 12 = 4096
                    22 - Result = 32 - 22 i.e 10 - No Of Devices / IP Addresses - 2 ^ 10 = 1024 
                    24 - Result = 32 - 24 i.e 8  - No Of Devices / IP Addresses - 2 ^ 8 = 256

    -> Network Security Group - NSG (Firewalls)

        -> Azure network security group is used to filter network traffic to and from 
        Azure resources in an Azure virtual network.

        -> A network security group contains security rules that allow or deny 
        inbound network traffic.

        -> For each rule, you can specify source and destination, port, and protocol.

            -> Myntra Web NSG 

                -> SSH Access (Admin Access For Linux Server) - Port 22 
                -> RDP Access (Admin Access For Windows Server) - Port 3389 
                -> HTTP Access (For Web Applications) - Port 80 

    -> Azure Public IP's 

        -> Public IP addresses allow Internet resources to communicate inbound to 
        Azure resources. Public IP addresses enable Azure resources to communicate to 
        Internet and public-facing Azure services.

        -> Myntra Web Server Needs Public IP To communicate from Internet 

        -> Myntra Database Server Doesn't Need Public IP, as Databases don't communicate 
        with internet directly. 

    
    -> Azure Network Interface Card - Azure NIC 

        -> In Azure, a Network Interface (NIC) is a crucial resource that connects a 
        Virtual Machine (VM) to a Virtual Network (VNet). 

        -> Each NIC acts as a virtual network adapter, allowing for IP configurations 
        (private/public, static/dynamic), association with Network Security Groups (NSGs) 
        for traffic filtering.

        -> An Azure Resource Manager (ARM) template is a JavaScript Object Notation (JSON) 
        file that defines the infrastructure and configuration for your Azure project 
        using a declarative syntax. It allows you to provision, manage, and deploy 
        all the necessary resources for your solution in a single, coordinated operation, 
        ensuring consistency and repeatability across different environments.
